Instalar Claude Code en Windows

Seguí estos 6 pasos en orden. No necesitás haber usado una terminal antes — cada comando se copia con un click.

Windows PowerShell
PS C:\Users\tu-usuario>
✓ Claude Code instalado correctamente
Necesitás una cuenta de pago de Claude (Pro, Max, Team o Enterprise). La cuenta gratuita de Claude.ai no funciona con Claude Code.
1

Instalar Git para Windows

Git es una herramienta que Claude Code usa por dentro. Sin ella funciona igual, pero con Git todo es más estable.

Entrá a esta página y descargá el instalador de 64 bits:

https://git-scm.com/downloads/win

Abrí el instalador y dejá todo por defecto, con una excepción: en la pantalla "Adjusting your PATH environment" elegí la opción del medio ("Git from the command line and also from 3rd-party software"). Después hacé click en "Install".

2

Abrir PowerShell

Ya viene instalado en Windows 10 y 11, no hay que descargar nada.

Presioná la tecla Windows, escribí PowerShell y abrí "Windows PowerShell" (ícono azul). Abrilo normal, no como Administrador.

3

Instalar Claude Code

Con PowerShell abierto, pegá este comando y presioná Enter:

irm https://claude.ai/install.ps1 | iex

Esto descarga e instala Claude Code automáticamente. No hace falta instalar Node.js ni nada más.

4

Verificar la instalación

Cerrá la ventana de PowerShell por completo (no alcanza con minimizarla), abrí una nueva y escribí:

claude --version

Si aparece un número de versión (por ejemplo 2.1.183 (Claude Code)), todo salió bien. Pasá al paso 6.

5

Si aparece un error "no se reconoce"

Es el error más común y se arregla en un minuto. Si PowerShell dice algo como "claude no se reconoce como nombre de un cmdlet", copiá y pegá esto:

[Environment]::SetEnvironmentVariable("Path", $env:Path + ";$HOME\.local\bin", "User")

Presioná Enter, cerrá la ventana por completo, abrí una nueva y probá de nuevo con claude --version.

6

Iniciar sesión

Escribí simplemente:

claude

Va a aparecer un menú para elegir el tipo de cuenta. Seleccioná la primera opción:

Claude account with subscription · Pro, Max, Team, or Enterprise

Se abre el navegador automáticamente. Iniciá sesión con tu cuenta de Claude.ai y confirmá el acceso. Si la terminal dice "Login successful", ya estás listo.

Listo. Con estos 6 pasos tenés Claude Code funcionando. Para usarlo en cualquier proyecto, abrí PowerShell dentro de esa carpeta y escribí "claude".
